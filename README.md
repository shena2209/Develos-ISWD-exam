# Street Foods | Night Food Cart 🍢
live site: https://github.com/shena2209/Develos-ISWD-exam.git
A modern, highly interactive, single-page website for a night food cart business. Built with HTML, Tailwind CSS, and GSAP for advanced scroll animations.

## 🚀 Features

*   **Responsive Design:** Looks great on mobile, tablet, and desktop screens.
*   **Glassmorphism UI:** Modern frosted-glass aesthetic using CSS variables and Tailwind utility classes.
*   **Dark Mode:** Includes a fully functional dark mode toggle that saves your preference in `localStorage`.
*   **Scroll Animations (GSAP):**
    *   Animated scrolling progress bar at the top of the page.
    *   Parallax floating background blobs.
    *   Pinned text reveal section (About).
    *   Horizontal scrolling menu carousel (Tonight's Menu) triggered by vertical scroll.
    *   Parallax card effects in the "Where we've cooked" section.
*   **Interactive Contact Form:** Prevents page reload on submit and shows a success message.
*   **Replay Intro Button:** Allows users to re-trigger the initial page load animation.
*   **External Links:** The menu items link to external recipe and inspiration pages (Epicurious, Instagram, Facebook, Adobe Stock).
